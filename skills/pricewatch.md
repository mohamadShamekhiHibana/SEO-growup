# Skill: پایش قیمت رقبا (هفتگی)
قوانین: فقط لینک‌هایی که کاربر در `data/inbox/competitor_links.csv` گذاشته (صفحه محصول ترب `torob.com/p/...`)؛ **هرگز** جستجو/API داخلی سایت‌ها یا کرال انبوه. قیمت مبنا (هزینه خرید) را نمی‌دانی؛ پیشنهاد کاهش قیمت نده مگر کاربر حاشیه سود بدهد.
1. `python3 agents/pricewatch/fetch.py` ← قیمت‌ها در SQLite (ریال ترب ÷۱۰ = تومان).
2. `python3 agents/pricewatch/report.py` ← data/reports/pricewatch/<شمسی>.md.
3. تفسیر: کدام محصول > ۱۰٪ گران‌تر، کدام ارزان‌تر (فرصت)، روند نسبت به هفته قبل (جدول competitor_prices). لینک‌های مشکوک (مدل متفاوت، فعال/نات‌اکتیو، ناموجود) را فهرست کن.
4. `cli learn` فقط برای الگوی معتبر؛ هشدار به مالک در گفتگو (نه تلگرام).
